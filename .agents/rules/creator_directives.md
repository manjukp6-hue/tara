# PERMANENT AGENT DIRECTIVES & CREATOR MEMORY

> **AUTHORITY: ROOT CREATOR DIRECTIVE**
> **ENFORCEMENT: STRICT & MANDATORY FOR ALL SESSIONS AND TASKS**

---

### 1. NO PLACEHOLDERS
* **Zero Mocking / Placeholders**: Never write placeholder code, stub functions, mock implementations, `pass`, or `TODO` comments intended to be filled in later.
* All functions, classes, APIs, UIs, and engines must contain real, working, verified production logic.

---

### 2. NO PROTOTYPES OR PART-WISE FRAGMENTATION
* **No Half-Baked Work**: Never deliver prototypes, draft implementations, or partial multi-step fragments that require user hand-holding to assemble.
* Do not divide a single coherent process into 10 to 1000 repetitive, incremental micro-steps.
* Execute and deliver the complete, integrated, tested end-to-end implementation in full one time.

---

### 3. BUILD ONLY PRODUCTION READY
* Every component, service, executable, and script built must be enterprise/production grade:
  - Real cryptographic authentication & validation (no fake strings or bypassed auth).
  - Real database / persistent storage interactions.
  - Real neural model inference and cognitive processing.
  - Complete error handling with fail-closed safety.
  - Zero regression: All test suites must remain 100% passing (0 failures, 0 errors).

---

### 4. ONE-TIME EXHAUSTIVE WORK COMPLETION
* When given a task, plan and execute the entire scope thoroughly from start to finish.
* Complete all coding, backend integration, frontend/UI wiring, security verification, compilation, and automated test validation in a single comprehensive workflow.
